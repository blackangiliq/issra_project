## نصائح للإلقاء

- **(ب) يتحكم بالعرض** ويتنقل بين الصور، و(أ) يحكي معظم الوقت.
- **الأرقام اللي لازم تنحفظ:** 27.6 ← 87.3 · ثلاث شركات · 39 معيار · 24 اختبار.
- **إذا ضاق الوقت:** احذفوا القسم ③ وخلّوه للأسئلة.
- **إذا عندكم عرض حي:**
  - شغّلوا `npm start` قبل العرض.
  - افتحوا لوحة الإدارة (`admin` / `Admin@12345`).
  - افتحوا بنافذة ثانية رابط قسم "المبيعات وخدمة العملاء" بشركة الرافدين، ومعرّفه `RFD-SL-6640`.

## أسئلة متوقعة — أجوبة قصيرة

| السؤال | الجواب |
|---|---|
| ليش كل قسم يجاوب لحاله؟ | كل مسؤول يعرف قسمه؛ التقييم أدق ويبين وين الضعف بالضبط. |
| شلون الرابط آمن؟ | رمز عشوائي + معرّف (عاملين)، حد لمحاولات التخمين، وتوليد رابط جديد يلغي القديم. |
| إذا نريد معيار جديد؟ | يضاف من محرر المعايير بدون برمجة، ويطلع للأقسام المحددة فوراً. |
| ليش NIST مو ISO؟ | ISO يحتاج نظام إدارة وشهادة مكلفة؛ NIST CSF 2.0 مرن ومجاني ويستهدف الشركات الصغيرة. |
| ليش ما استخدمتوا ذكاء اصطناعي؟ | ماكو بيانات تدريب موثوقة، والأمن يحتاج نتائج قابلة للتفسير. |
