## نصائح للإلقاء

- **قسّموا الشاشة:** (أ) يحكي و(ب) يتحكم بالعرض، وبالأقسام اللي يحكي بيها (ب) يتبادلون.
- **الأرقام الثلاثة اللي لازم تنحفظ:** 28.6 ← 86.8 · 58 توصية · 15 اختبار.
- **إذا الوقت ضاق:** احذفوا جملة "التقنيات" بالخاتمة وجملة "المكاسب السريعة".
- **إذا عندكم عرض حي:** شغّلوا `npm start` قبل العرض وسجّلوا دخول مسبقاً، وافتحوا تقرير دراسة الحالة جاهز.

## أسئلة سريعة متوقعة بعد العرض

| السؤال | جواب قصير |
|---|---|
| ليش NIST مو ISO 27001؟ | ISO يحتاج نظام إدارة كامل وشهادة ومكلف؛ NIST CSF 2.0 مرن ومجاني وأضاف الحوكمة واستهدف الشركات الصغيرة. |
| شنو اللي يخليها "ذكية"؟ | التخطي بنوعين، الأوزان المتكيّفة، الثغرات المركّبة، ترتيب التوصيات حسب الأثر مع التنبؤ بالدرجة، وتتبع التقدم. |
| ليش ما استخدمتوا ذكاء اصطناعي؟ | ماكو بيانات تدريب موثوقة، والأمن يحتاج نتائج قابلة للتفسير؛ القواعد واضحة ومختبرة. |
| التخطي ما يرفع الدرجة بالغلط؟ | لا — السؤال المتخطى لأن المتطلب مفقود يُحسب صفر، والمستبعد بس غير المنطبق فعلاً. |
